# Graphify & Serena: Advanced Code Analysis, Dependency Mapping, and AI Test Engineering

> **Executive Overview**  
> Modern AI coding agents (like Claude Code, Cursor, Codex) often suffer from the "Token Tax" — repeatedly reading hundreds of source files to understand codebase architecture. **Graphify** and **Serena** solve this problem at two complementary tiers:
> - **Graphify** operates at the **macro/architectural level**, turning your codebase, docs, and infrastructure into a persistent, queryable Knowledge Graph.
> - **Serena** operates at the **micro/symbol level**, providing IDE-like semantic symbol navigation (LSP, definition lookups, cross-file references) via the Model Context Protocol (MCP).
> 
> Together, they form a powerful dual-engine context layer that drastically reduces token consumption, eliminates hallucinated code relationships, and powers advanced QA automation workflows like **Blast Radius analysis** and **Prompt Chained Test Engineering**.

## 2. Graphify: Macro Architectural Knowledge Graph

### Core Capabilities
* **Deterministic AST Parsing:** Uses Abstract Syntax Tree (AST) parsing (e.g., Tree-sitter) to parse code, SQL schemas, infrastructure files (Terraform), and documentation into typed nodes and edges.
* **Query-First Traversal:** Replaces costly full-repo file reads or raw `grep` commands with scoped graph queries (`graphify query "<question>"`), traversing multi-hop dependencies in milliseconds.
* **Cross-Component Mapping:** Maps relationships across microservices, databases, and multi-module monorepos within a unified workspace.
* **Massive Token Reduction:** Benchmarks demonstrate up to **27x to 71x token savings** on large codebases by eliminating repetitive file scanning per prompt session.

### Primary Role in AI Workflows
* High-level architectural understanding and component boundary discovery.
* Multi-hop dependency tracking across microservice borders.
* Initial codebase onboarding for AI agents and continuous regression testing guidance.

---

## 3. Serena: Micro Symbol-Level IDE Engine

### Core Capabilities
* **Language Server Protocol (LSP) Integration:** Integrates with language servers to parse semantic symbols (classes, functions, methods, interface implementations).
* **Symbol-Level Navigation:** Enables AI agents to execute "Go to Definition", "Find All References", and symbol-aware refactoring directly without reading unneeded surrounding context.
* **Model Context Protocol (MCP) Support:** Connects seamlessly as an MCP server to Claude Code, Claude Desktop, Cursor, and VS Code.
* **Token & Context Optimization:** Reduces token usage by up to **70%** during deep bug fixes and feature implementations by presenting only the relevant function definitions and callers.

### Primary Role in AI Workflows
* Precise root-cause investigation and function impact tracing.
* Atomic, symbol-aware code refactoring and cross-file reference updates.
* High-precision code navigation for complex business logic.

## 5. The 5-Stage Test Engineering Pipeline (Prompt Chaining)

When Graphify and Serena are combined with AI coding agents (like Claude Code), QA teams can implement a **structured 5-stage test harness pipeline**:

```
[1. Requirement Analysis] ──► [2. Blast Radius Detection] ──► [3. Test Charter Generation]
                                                                        │
                                                                        ▼
                                  [5. Bug Finding] ◄─── [4. Test Case Design]
```

### Stage 1: Requirement Analysis
* **Objective:** Parse raw user stories or feature requirements into explicit Acceptance Criteria.
* **Role:** Ensures the AI agent understands business rules before inspecting code.

### Stage 2: Blast Radius Analysis
* **Objective:** Detect modified files, git branch changes, and impacted dependent modules over the **Graphify Knowledge Graph**.
* **Role:** Delimits the "hazard zone" or impact radius created by recent pull requests or code edits (essential for **Sanity Testing**).

### Stage 3: Test Charter Generation
* **Objective:** Conduct time-boxed exploratory exploration focused on identified risk zones.
* **Role:** Establishes test objectives, pre-conditions, and test oracles without jumping straight into rigid test cases.

### Stage 4: Test Design & Prioritization
* **Objective:** Generate structured, actionable test cases categorized strictly into **High**, **Medium**, and **Low** priorities.
* **Role:** Employs precise symbol references from **Serena** to ensure test steps target exact functions and endpoints without hallucinated parameters.

### Stage 5: Bug Finding & Root Cause Analysis
* **Objective:** Execute tests, trace failures back to specific symbols, and assess confidence scores.
* **Role:** Uses Serena to inspect runtime stack traces, database states, and function call chains to pinpoint precise bug locations.

## 6. Installation & Activation Workflow

### Step 1: Install Package Manager & Tools
```bash
# Install UV package manager (Mac / Linux / Windows)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Global installation of Serena
uv tool install serena
```

### Step 2: Initialize Serena in Project Workspace
```bash
# Navigate to your project directory
cd /path/to/your/project

# Initialize Serena locally in workspace
serena init

# Link Serena MCP server to Claude Code
serena setup claude-code
```

### Step 3: Activate Serena in Claude Session
```text
In Claude Code / Desktop prompt:
"Can you access Serena? Please activate Serena inside this project."
```
> *This creates the local `.serena/` index and project memory layer, allowing Claude to navigate symbol definitions effortlessly.*

## 7. Key Takeaways & Best Practices

1. **Dual-Engine Synergy:** Graphify establishes the system map; Serena navigates the individual paths. Using both provides optimal AI agent performance and lowest token consumption.
2. **Context Window Protection:** By enforcing small, specialized skill files (<200 lines) and structured prompt chaining, you prevent context overflow and AI hallucinations.
3. **Targeted Testing:**
   * Use **Graphify + Blast Radius** for fast, targeted **Sanity / Regression Testing** on PRs.
   * Use **Serena** for deep-dive **Root Cause Analysis** and function-level verification.
